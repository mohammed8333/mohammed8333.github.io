## 🚀 المميزات الرئيسية للمشروع

### 1. موقع العملاء (`website/index.html`)
- **تصميم مصري وهوية بصرية دافئة:** ألوان المطاعم المبهجة، خط Cairo، الوضعان الليلي والنهاري (Light/Dark)، واللغة العربية الافتراضية مع دعم كامل للغة الإنجليزية (RTL/LTR).
- **قائمة طعام شاملة:** بيتزا (إيطالي وشرقي)، كريب، برجر، سندوتشات، فطير مشلتت وحلو وحادق بالسمن البلدي، حواوشي، وإضافات ومشروبات.
- **تخصيص الوجبات والأسعار اللحظية:** اختيار الحجم (صغير، وسط، كبير، عائلي)، اختيار إضافات متعددة، وملاحظات خاصة.
- **قسم العروض والخصومات والكومبو:** عروض حصرية موفرة قابلة للإضافة المباشرة للسلة مع احتساب التوفير تلقائياً.
- **سلة مشتريات تفاعلية ومستمرة:** تتيح التبديل بين توصيل منازل واستلام من الفرع مع تطبيق أكواد الخصم الترويجية (مثل `SHEIKH10`).
- **إتمام الطلب ومشاركة موقع GPS:** تحديد موقع العميل بالأقمار الصناعية بنقرة واحدة لتسهيل وصول الديلفري.
- **التكامل مع واتساب الرسمي (+201112962692):** توليد رسالة واتساب تفصيلية بالطلب والفاتورة مع التنبيه الرسمي بأن الطلب قيد التأكيد.

### 2. لوحة تحكم الإدارة المستقلة (`website/admin.html`)
- **شاشة دخول آمنة:** مع إمكانية تعديل اسم المستخدم وكلمة المرور من داخل الإعدادات.
- **سجل الطلبات الواردة:** استعراض الطلبات، زر اتصال مباشر، وزر مراسلة واتساب فوري للعميل، وتحديث الحالات.
- **إدارة قائمة الطعام:** تعديل الأسعار، زر إضافة وجبة جديدة، زر اعتماد الصنف (عينة / معتمد رسمي)، وتفعيل/تعطيل التوفر.
- **إدارة العروض والخصومات:** إضافة وتعديل العروض والكومبو، وإدارة أكواد الكوبونات الترويجية.
- **إعدادات المطعم:** تعديل الهواتف، العنوان، رسوم التوصيل، ونص الشريط الترويجي.

### 3. خادم الباك إند (`backend/PizzaAwladAlsheikh.API`)
- مطور بـ **ASP.NET Core Web API** (.NET 10).
- يدعم **PostgreSQL** و **SQLite**.
- مصادقة آمنة عبر **JWT Tokens**.
- يخدم الموقع الإلكتروني مباشرة عبر مجلد `wwwroot` كـ Full-Stack App.

## 🛠️ كيفية التشغيل محلياً

### تشغيل الموقع الإلكتروني:
يمكنك فتح `website/index.html` في أي متصفح، أو تشغيله عبر سيرفر ويب:
```bash
# عبر Node.js:
npx serve website -l 3000

# عبر Python:
cd website && python -m http.server 8080
```

### تشغيل الخادم الخلفي (ASP.NET Core):
```bash
cd backend/PizzaAwladAlsheikh.API
dotnet run
```
ثم فتح المتصفح على: `http://localhost:5000`
