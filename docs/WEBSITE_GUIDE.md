# دليل تشغيل موقع مطعم بيتزا أولاد الشيخ (Pizza Awlad Alsheikh Web Application)

تم بناء وتطوير موقع إلكتروني احترافي متكامل ومتجاوب لمطعم **بيتزا أولاد الشيخ** (فرع امتداد شارع الوحدة، المنيرة، إمبابة، الجيزة) وفق أحدث معايير تصميم وتطوير مواقع المطاعم العالمية والمحلية في مصر.

---

## 🌟 مميزات الموقع الرئيسية

1. **واجهة مستخدم عصرية وهوية مصرية أصيلة:**
   - تصميم بألوان دافئة مستوحاة من ألوان البيتزا والمطاعم (الأحمر الطماطمي `#c62828`، البرتقالي الشيدر `#ff6f00`، والداكن `#121214`).
   - خط **Cairo** المعتمد للنصوص العربية والإنجليزية.
   - دعم كامل للغة العربية افتراضياً مع الاتجاه من اليمين لليسار (RTL)، مع زر فوري للتحويل للغة الإنجليزية (LTR).
   - دعم الوضعين الليلي والنهاري (Light & Dark Theme).
   - متجاوب بالكامل مع كافة الشاشات (الموبايل، التابلت، والكمبيوتر).

2. **قائمة طعام شاملة وتصنيفات أولاد الشيخ:**
   - 1. بيتزا (إيطالي وشرقي).
   - 2. كريب (حادق وحلو).
   - 3. برجر.
   - 4. سندوتشات.
   - 5. فطير مشلتت وحلو وحادق بالسمن البلدي.
   - 6. حواوشي بلدي وفراخ.
   - 7. إضافات ومشروبات.
   - شريط بحث فوري في أصناف المنيو وتصفية سريعة.

3. **حماية الشفافية وشارة العينات التجريبية:**
   - جميع الأصناف والأسعار الأولية مزودة بشارة واضحة:  
     `[عينة تجريبية - تتطلب تأكيد الإدارة]`  
     لحين قيام إدارة المطعم باعتمادها من خلال لوحة التحكم.

4. **تخصيص الوجبات وحساب الأسعار الديناميكي:**
   - إمكانية اختيار حجم البيتزا أو الوجبة (صغير، وسط، كبير، عائلي).
   - إمكانية إضافة إضافات اختيارية (جبنة موتزاريلا زيادة، أطراف محشوة، مشروم، صوصات...).
   - حقل ملاحظات خاصة (مثال: بدون بصل، صوص حار جانبي...).
   - عداد كمية تفاعلي وحساب السعر الإجمالي في الوقت الفعلي.

5. **عربة تسوق متطورة (Slide-over Cart):**
   - حفظ تلقائي مستمر للسلة في المتصفح (`localStorage`).
   - خيار التبديل بين **توصيل منازل** أو **استلام من الفرع** (مع جعل رسوم التوصيل 0 ج.م في حال الاستلام).
   - حساب المجموع الفرعي، رسوم التوصيل، والإجمالي بالجنيه المصري (ج.م).

6. **إتمام الطلب وتحديد الموقع عبر الـ GPS:**
   - إدخال الاسم، ورقم الهاتف المحمول المصري (التحقق من صيغة 11 رقماً تبدأ بـ 01).
   - اختيار المنطقة (امتداد شارع الوحدة، المنيرة الغربية، المنيرة الشرقية، بشتيل، الوراق، إلخ...).
   - زر مدمج لتحديد موقع العميل بدقة عبر الأقمار الصناعية (`navigator.geolocation`) وتوليد رابط مباشر لخريطة جوجل.

7. **التكامل الرسمي مع واتساب المطعم (`+201112962692`):**
   - توليد رسالة واتساب منسقة ومفصلة بنقرة واحدة تحتوي على:
     - رقم الطلب المرجعي `#ORD-XXXXX`.
     - بيانات العميل، رقم الهاتف، العنوان، ورابط الـ GPS.
     - تفاصيل الأصناف، الأحجام، الإضافات، والكميات.
     - الفاتورة الإجمالية وطريقة الدفع.
     - تنبيه واضح: **"الطلب معلق بانتظار رد وتأكيد المطعم وتحديد وقت التجهيز والتوصيل"**.

8. **لوحة تحكم إدارة المطعم المستقلة (Dedicated Admin Page - `admin.html`):**
   - صفحة مستقلة ومنفصلة بالكامل مخصصة لمدير ومسؤولي المطعم.
   - تسجيل دخول آمن ببيانات الاعتماد:  
     - **اسم المستخدم:** `admin`  
     - **كلمة المرور:** `AdminPassword123!`
   - **سجل الطلبات الواردة:** استعراض كافة الطلبات، فلترة حسب الحالة، بحث برقم الطلب والعميل، زر اتصال مباشر، زر واتساب للتواصل السريع مع العميل، ورابط موقع الـ GPS.
   - **قائمة الطعام والأسعار:** تعديل الأسعار، زر إضافة صنف جديد، تعديل حالة التوفر، والتبديل الفوري بين (عينة تجريبية / معتمد رسمي).
   - **الإحصائيات والملخص:** عدد الطلبات الكلي، الطلبات المعلقة، إجمالي المبيعات، وعدد الأصناف.
   - **إعدادات المطعم:** أرقام الاتصال، رقم الواتساب، العنوان، رسوم التوصيل، ونص الشريط الإعلاني.
   - يمكن فتحها مباشرة عبر الرابط `/admin.html` أو النقر على أيقونة الإدارة في الموقع.

## 🚀 طرق تشغيل الموقع

### الطريقة الأولى: التشغيل الشامل مع السيرفر الخلفي (ASP.NET Core API)
يخدم الموقع الإلكتروني وواجهة الـ REST API معاً على المنفذ `http://localhost:5000`:
```bash
cd backend\PizzaAwladAlsheikh.API
dotnet run
```
ثم افتح في متصفحك:  
👉 **`http://localhost:5000`**

---

### الطريقة الثانية: التشغيل المباشر عبر Node.js (npx)
من المجلد الرئيسي للمشروع:
```bash
npx serve website -l 3000
```
ثم افتح:  
👉 **`http://localhost:3000`**

---

### الطريقة الثالثة: التشغيل عبر بايثون (Python HTTP Server)
```bash
cd website
python -m http.server 8080
```
ثم افتح:  
👉 **`http://localhost:8080`**

---

### الطريقة الرابعة: الفتح المباشر في المتصفح
يمكنك النقر المزدوج على ملف:  
`d:\بيتزا\website\index.html`  
وسيفتح الموقع فوراً في متصفحك (Chrome, Edge, Firefox) ويعمل بكامل وظائفه مع التخزين المحلي.

## 📂 هيكل ملفات الموقع (`website/`)

```
d:\بيتزا\website\
├── index.html         # الصفحة الرئيسية الكاملة لطلبات العملاء
├── admin.html         # صفحة لوحة تحكم إدارة المطعم المنفصلة
├── css\
│   ├── style.css      # ملف تنسيقات موقع العملاء (RTL/LTR، الثيمات، المودالات، السلة)
│   └── admin.css      # ملف تنسيقات لوحة الإدارة (Sidebar, Stats, Tables, Badges)
└── js\
    ├── data.js        # البيانات الأولية: المنتجات، الأحجام، الإضافات، المناطق، والإعدادات
    ├── app.js         # محرك موقع العملاء: السلة، الواتساب، GPS، واللغات
    └── admin.js       # محرك لوحة الإدارة: إدارة الطلبات، الأسعار، المنتجات، والإعدادات
```

كما تم نسخ كامل هذه الملفات تلقائياً إلى مجلد `wwwroot` في مشروع الـ Backend ليعمل كـ Full-Stack Web Application متكامل.
